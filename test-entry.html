FocusDesk · 测试入口

平板专注工作台（番茄钟 + 待办 + 时间块）。下面每个链接都写明「预期结果」，点开即可人工核对。

1) 正常入口（空数据） — ./index.html
预期：深色看板，三栏（左：时钟+番茄钟，中：待办，右：时间块时间轴）；顶部「屏幕常亮」状态显示「已开启」或明确的降级提示（不会假装生效）。
2) 演示数据入口 — ./index.html?seed=1
预期：待办 3 条（1 条已完成）；今天时间轴出现 09:00 学习 / 10:00 休息 / 10:30 写代码 / 14:00 阅读 四个块；当前时间段（若在区间内）高亮。
3) 自检探针（机器可读） — ./index.html?probe=1&nomotion=1
预期：标签页标题变成 PROBE-OK todos=.. blocks=.. phase=focus running=0 wake=yes sw=yes theme=dark。
命令行核对：chrome --headless=new --dump-dom "file:///.../index.html?probe=1&nomotion=1" | grep -o "PROBE-OK[^<]*"
4) 自动启动计时器（视觉核对） — ./index.html?seed=1&auto=1&nomotion=1
预期：番茄钟立即进入「进行中…」，圆环开始走，按钮变为「暂停」。

手工检查清单

  • ☐ 番茄钟：开始 → 暂停 → 继续 → 跳过 → 结束本阶段，按钮文字与状态同步；蓝色圆环随剩余时间收缩。
  • ☐ 刷新页面后：若计时中，剩余时间继续走；若已走完，弹提示并按规则进入休息/专注。
  • ☐ 待办：添加 / 勾选完成 / 取消完成 / 双击改名 / 删除 / 过滤（全部·未完成·已完成）。
  • ☐ 时间块：空白处点击新建 1 小时；按住拖动圈选自定义时段；拖动块移动、拖上下边缘改时长；点击块编辑/删除。
  • ☐ 重叠：两个块时间相交时边框变红并弹提示，不会自动覆盖。
  • ☐ 联动：待办「专注」按钮 / 时间块编辑里的「用关联待办专注」→ 番茄钟显示当前任务；专注结束后「今日专注次数 / 累计分钟」增加。
  • ☐ 位移：等待 60–120 秒，背景光斑与时钟有极轻微平滑位移；点击、拖拽不受影响。
  • ☐ 设置：修改各时长、长休息轮次、位移间隔、时间轴范围、浅色主题；保存后立即生效。
  • ☐ 导出 → 得到 JSON 备份；清空后导入该文件 → 数据恢复。

自动化命令（在项目目录内）

# 1) 静态语法检查
node --check app.js

# 2) 本地起服务（PWA / 屏幕常亮需要安全上下文，file:// 只能验证界面）
python3 -m http.server 8173

# 3) 无头探针（Windows Chrome 路径示例）
"C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=new --disable-gpu ^
  --virtual-time-budget=9000 --dump-dom ^
  "http://localhost:8173/index.html?probe=1&nomotion=1" | findstr PROBE-OK

已知平台限制

  • 屏幕常亮依赖浏览器 Screen Wake Lock API，且需要安全上下文（https:// 或 http://localhost）。用局域网 http 打开时可能不可用。
  • 系统省电模式 / 浏览器后台限制可能强行回收常亮，页面会显示「已释放」而非假装正常。
  • PWA 安装（Service Worker）同样需要安全上下文，file:// 打开时不生效。
  • 清除浏览器数据会清空本地数据，请用「导出备份」留底。
